# Returns policy

Approved by the online team lead and finance, 2026-03-01.

- **Online orders:** returns accepted within **30 days** of delivery, unworn, with the label on.
- **Store purchases:** returns or exchanges within **30 days** in any Este store, with the receipt.
- **Sale items:** exchange or store credit only, no refund.
- **Refunds** go back to the original payment method within **5 working days** of the return
  reaching us.
- **Online returns are free** in Portugal and Spain. Other countries pay the return shipping.
- Every online return is put back into stock in Warehouse Online and must be booked into Sage the
  same week.
