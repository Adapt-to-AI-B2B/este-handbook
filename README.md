# Este — team handbook (practice project)

A small practice project for learning how Claude Code works with files. **Este is a fictional
apparel brand**: every name, policy and number here is invented.

It holds documents only: how the company works, its policies, its words, some meeting notes.
No data tables yet; those come in Lesson 2.

## Get it
1. On this page, click the green **Code** button → **Download ZIP**.
2. Unzip it, move the folder into your **projects** folder and rename it to `este-handbook`.
3. In VS Code: **File → Open Folder** → `este-handbook`.

## What's inside
| File or folder | What it is |
|---|---|
| `CLAUDE.md` | What Claude reads at the start of every session |
| `MEMORY.md` | The team's decisions and their reasons; CLAUDE.md loads it every session |
| `.claude/rules/` | Rule files: extra instructions, some only for certain folders |
| `docs/` | The handbook: company, voice, returns, words we use, suppliers |
| `docs/meetings/` | Notes from team meetings |
| `docs/meetings/CLAUDE.md` | Extra instructions for this folder only, read when Claude works here |
| `drafts/customers/` | Where replies to customers are drafted |
