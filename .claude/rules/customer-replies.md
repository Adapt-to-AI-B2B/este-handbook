# Replies to customers

- Write in the voice described in `docs/brand-voice.md`.
- Quote the returns policy from `docs/returns.md`; don't paraphrase the time limits, because a
  paraphrase is how a 30-day window turns into "about a month".
- Sign off as "The Este team", never with a person's name, because replies are shared between
  stores.
